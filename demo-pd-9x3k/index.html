🗝️ 1.5+1.6 確認用デモ — 端末内で完結・データは外部送信されません
① 1.5「カタカナ・アルファベット暗号化」の確認のしかた
  1. 下のメニュー「作成」→ カタカナや英語(ABC)を含む文章を入力(例: 「カタカナとABCのテスト！タヌキ」)
  2. 暗号を選んで「暗号文をつくる」→ 暗号文にカタカナ・英字が含まれることを確認(以前はカタカナが消えていました)
  3. 暗号文とキーをコピー → メニュー「解読」で貼り付けて「復号する」→ カタカナ・英字がそのまま戻ることを確認
※「子音変換」だけは五十音表のしくみのためアルファベットは変換されません(画面にも注記あり)。他の暗号では英字も暗号化されます。
② 1.6「型フィルター」の確認のしかた
  1. 下のメニュー「画像暗号」→ 画像を選ぶ → 「🎭 型フィルターをかける」にチェック
  2. 型(ハート/◯/☆/△/もや)と透過度を選んで「モザイク化する」→ 型が乗ったモザイクを確認
  3. 「モザイク画像を保存」でPNGが保存されます(スマホは共有/ダウンロード)。キーもコピー
  4. メニュー「画像復元」で 保存したPNG+キー →「復元する」→ 元の画像にほぼ戻ることを確認(わずかな色ずれが出ることがあります)
  5. 型を「なし」にした場合は従来どおり完全に元どおりに戻ります
※このデモは全種類が使えます(製品の無料版は「なし/もや/ハート/◯」の4種。有料版は全種)。漢字→ひらがな変換(辞書)はデモでは動きません。

あそびかた

  1. 「作成」で文章を入力し、好きな暗号を組み合わせて暗号文をつくる
  2. できあがった暗号文と暗号化キーを、別々の方法で相手に渡す(キーをクイズにして出題しても◎)
  3. 受け取った人は「解読」に暗号文とキーを入れて、もとの文章にもどす
  4. 「画像暗号」では写真をモザイクアートに変えられる。もどすには「画像復元」でモザイクPNGと画像用キーを使う

備考: キーの読み方

※キーの仕組みの種明かしです。クイズとして楽しみたい人は読まないのがおすすめ。
キーは区切りごとに暗号1つ。先頭の数字が暗号の種類、続く数字が設定です。

1たぬき暗号(量1〜3+シード2桁+まぎれこませる文字)
2子音変換暗号(ずらす段数)
3エニグマ式暗号(ダイヤル3つ)
4逆さ読み
5回転(ずらす文字数)

例: 「1237と・23・4」= たぬき(量2・シード37・「と」)→ 子音3段 → 逆さ読み

機能の開放

開放すると「作成」画面に「漢字もひらがなに変換」の選択肢が追加されます。
※動作が安定しない・変換辞書(約18MB)の読み込みに時間がかかることがあります。読み込めない場合は漢字そのままで暗号化します。

ご注意

  • 「漢字もひらがなに変換」(ベータ版)は、この設定画面の「機能の開放」でオンにできます。通信状況により変換できないことがあります(その場合は漢字そのままで暗号化されます)
  • 暗号化キーがないと復号できません。キーはアプリに保存されないので、大切に保管を
  • モザイク画像はPNGのまま共有してください(JPEG変換やスクショでは復元できません)。LINEなどで送るときは「ファイルとして送信」を使い、受け取ったら「ファイル」から選んでください
  • 本アプリの暗号は遊び・学習目的です。大切な情報の保護には使わないでください
  • 入力した文章・画像・キーはすべて端末内で処理され、外部に送信されません
